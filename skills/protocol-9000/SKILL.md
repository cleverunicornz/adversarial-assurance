# Lane 9000 — Miscellaneous

The named escape hatch, so that work with no other home still carries an
address and still runs the same grammar. Small and complete is not by itself
a reason to arrive here — the lanes without family skills already run the
universal procedure directly and impose no ceremony floor.

Refusal: work that intends to be complete in its own right does not belong
here; name its true lane at the door and route it there.

Flow: no predecessor and no successor — the receiver is named at the moment
of routing, never in advance, which is why this lane declares none.
