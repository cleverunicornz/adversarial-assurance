# Use-Derived State — The Posture

The canon is `architecture/use-derived-state/`: the Nine Commandments
(`nine-commandments.md`, the chartered root) and the binding charter
(`AGENTS.md`). Root policy's standing ruling makes them non-optional: any
work touching durable state resolves that node before design begins. This
skill is the working posture that ruling assumes — loaded at task start,
named into goals so it survives context loss, re-applied at the moment your
next move would shape state. It restates no law; where this file and the
canon diverge, the canon governs and the divergence is a defect here.

Present status and conduct for the discipline live at
`architecture/risk/use-derived-state/`. Resolve it with the register sweep
you already owe before any work.

## The Map — the Nine in repository organs

The Nine are not a second methodology; they are the promise plane for
state. Their organs land on the practice you already run:

- **Typed transitions** (the vocabulary) are the promise's *existence*
  third, pushed to the **unrepresentable** rung: what the application does
  is a word; what it cannot mean has no spelling.
- **One writer per lineage, proven by fence** is *exclusivity* on the
  **unreachable** rung — the same "seams, single writer, CAS" root policy
  already names. The head swap is the fence; convention is not.
- **Typed refusal** is *domain* on the **rejected** rung: inadmissible
  operations receive a type and never enter history.
- **Gauges** are oracles passed through both-polarity known-answer
  controls and **pinned as gates** — the detected rung, made permanent.
  `$oracle` owns the comparator practice; `$state-gauge` owns the state
  gauge classes.
- **The fold** is root law "state is queryable, never remembered" made
  executable: every truth re-derivable from the substrate so an oracle can
  always compare against the actual.
- **Projections** are witness-plane discipline applied to data:
  generation-fenced, disposable, rebuildable, never truth.
- **Violation signatures** (the canon's table) are `$gravity`-class
  tells: recognition triggers, not a checklist to file.

## The Tells — when to stop mid-motion

Stop and re-derive from the canon the moment you notice yourself, or the
text in front of you, doing any of these:

- Reaching for an engine, ORM, schema, or "just a table" before the use
  inventory exists. Schema-first is the old geometry's founding move, and
  it is the trained default — expect it in yourself first.
- Admitting a second writer to a lineage "temporarily", or holding
  ownership by convention without a fence.
- Storing meaning as a generic blob "for flexibility" — an untyped
  accept-anything surface breaks vocabulary and load-bearing law at once.
- Letting an invariant span lineages with no declared choreography.
- Mutating a canonical object in place, or reinterpreting recorded
  transitions under new rules instead of an explicit versioned evolution.
- Calling something a cache or a projection while nothing canonical can
  rebuild it — whatever lacks a rebuild procedure is claiming to be truth.
- Standardizing on first use: a shared helper, envelope, or layout
  promoted because one protocol has it. The floor discipline requires two
  real protocols and a human gate; until then shared state artifacts do
  not exist, and text claiming one is a register defect.
- Wiring anything forward-facing to the shelved engine. The shelf
  (`architecture/risk/storage-substrate/`) is a lesson, not an option;
  re-entry is a human-named, use-first act only.

## The Direction-of-Arrival Test

Concepts survive; thrones do not. Vector, graph, lexical, temporal, and
key-value shapes are legitimate as *derived* access shapes and
projections. The same shape is forbidden when it arrives first and the
application is pressed into it. The mechanical check: **what exists first
in the record — the use inventory or the structure?** Use-first is earned;
structure-first is the old geometry wearing new words, whatever the
structure is.

## Jurisdiction And Routing

Adopting the discipline is itself use-derived. A domain that genuinely
does not collapse — arbitrary ad-hoc relational querying, contention no
seam can decompose, cross-record invariants that resist choreography — is
a recorded verdict and a human conversation, never a silent engine
adoption. Route by the moment's need:

- Authoring a protocol or design package for an application:
  `$state-modeling`.
- Building, qualifying, or attacking a protocol's proofs, or qualifying a
  backend beneath one: `$state-gauge`.
- The Nine underdetermine a live choice: that is a genuine design
  decision — surface it to the human. Never fill the gap with the old
  geometry's defaults.
